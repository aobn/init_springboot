## 目录结构说明

### 核心业务目录

| 目录 | 说明 | 命名规范 |
|------|------|----------|
| **api/** | API接口控制器目录 | 按规则要求，所有API接口必须放在此目录 |
| **entity/** | 实体类目录 | 数据库表对应的实体类，使用Entity后缀 |
| **mapper/** | 数据访问层目录 | MyBatis接口，使用Mapper后缀 |
| **service/** | 服务层目录 | 业务逻辑接口，使用Service后缀 |
| **service/impl/** | 服务实现目录 | 服务接口实现类，使用ServiceImpl后缀 |
| **config/** | 配置类目录 | Spring配置类，使用Config后缀 |
| **common/** | 通用类目录 | 公共工具类和响应格式 |
| **exception/** | 异常处理目录 | 自定义异常和全局异常处理器 |

### 配置文件目录

| 文件 | 说明 | 用途 |
|------|------|------|
| **application.yml** | 主配置文件 | 通用配置和默认配置 |
| **application-dev.yml** | 开发环境配置 | 开发环境专用配置（数据库连接等） |
| **application-prod.yml** | 生产环境配置 | 生产环境专用配置（预留） |

### 预留扩展目录

| 目录 | 说明 | 用途 |
|------|------|------|
| **dto/** | 数据传输对象目录 | API请求/响应对象，使用DTO后缀 |
| **util/** | 工具类目录 | 通用工具类，使用Utils后缀 |
| **constant/** | 常量类目录 | 系统常量定义，使用Constants后缀 |
| **templates/** | 模板文件目录 | Thymeleaf等模板文件 |
| **mapper/xml/** | MyBatis XML目录 | SQL映射文件 |

## 文件命名规范

### Java类文件命名
- **控制器类**: `*Controller.java` (如: UserController.java)
- **服务接口**: `*Service.java` (如: UserService.java)
- **服务实现**: `*ServiceImpl.java` (如: UserServiceImpl.java)
- **实体类**: `*Entity.java` (如: UserEntity.java)
- **数据访问**: `*Mapper.java` (如: UserMapper.java)
- **配置类**: `*Config.java` (如: WebConfig.java)
- **异常类**: `*Exception.java` (如: BusinessException.java)

### 包命名规范
- **根包**: `com.example.demo`
- **控制器包**: `com.example.demo.api` (特殊：放在api目录下)
- **服务包**: `com.example.demo.service`
- **实体包**: `com.example.demo.entity`
- **数据访问包**: `com.example.demo.mapper`
- **配置包**: `com.example.demo.config`

## 项目特点

### ✅ 符合规则要求
1. **API接口放在api目录**: 严格按照规则文档要求
2. **Java命名规范**: 遵循驼峰命名和标准后缀
3. **统一响应格式**: 使用ApiResponse统一格式

1. **分层架构**: Controller → Service → Mapper 清晰分层
2. **配置分离**: 不同环境使用不同配置文件
3. **异常处理**: 全局统一异常处理机制
4. **依赖注入**: 使用Spring的依赖注入
